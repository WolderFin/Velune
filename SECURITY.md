# Безопасность Velune

## Проверка загрузки

Скачивайте Velune только из Releases официального репозитория WolderFin. Для каждого релиза публикуется `SHA256SUMS.txt`. Сверить файл можно командой:

```powershell
Get-FileHash .\Velune.exe -Algorithm SHA256
```

Значение должно полностью совпадать со строкой `Velune.exe` в `SHA256SUMS.txt`. После внедрения подписи проверяйте также свойства файла → **Цифровые подписи**, либо:

```powershell
Get-AuthenticodeSignature .\Velune.exe | Format-List Status,SignerCertificate
```

Статус должен быть `Valid`, а издатель должен совпадать с издателем, указанным WolderFin в описании релиза.

## Что делает приложение

Velune читает метаданные активных Windows Media Session, хранит обложки в памяти и открывает локальный HTTP-сервер только на `127.0.0.1:8765` для интерфейса и OBS. Приложение не загружает и не запускает удалённый код, не добавляет себя в автозагрузку и не отправляет сведения о треках во внешние сервисы.

## Сообщение об уязвимости

Не публикуйте потенциальную уязвимость вместе с готовым способом эксплуатации в Issues. Свяжитесь с WolderFin через почту [velune@wolderfin.su](mailto:velune@wolderfin.su) и укажите затронутую версию, ожидаемое и фактическое поведение, а также минимальные шаги воспроизведения.

Антивирусное срабатывание приложите с SHA-256, версией Velune, названием движка и детекта, ссылкой на отчёт VirusTotal и источником скачивания файла.
