<p align="center"><strong>Любимый трек — часть твоего кадра.</strong><br>Музыкальный оверлей для OBS с настольной настройкой и работой в фоне.</p>

**Velune** читает текущий трек через Windows Media Session API и показывает обложку, исполнителя, название и прогресс в прозрачном источнике OBS. Без аккаунтов и облачных сервисов — музыка и настройки остаются на твоём компьютере.

> **Условия использования:** бесплатно для некоммерческих целей. Монетизированные, спонсорские и платные трансляции требуют предварительного письменного разрешения WolderFin и отдельного соглашения. См. [LICENSE](LICENSE).

## Что умеет Velune

- Автовыбор активного трека из Яндекс Музыки, Яндекс Браузера или другого источника Windows Media Session.
- Локальный Browser Bridge для VK и Яндекс Музыки, когда браузер не публикует медиасессию Windows.
- Четыре темы и независимые переключатели подложки и свечения.
- Живой предпросмотр и пример оформления без воспроизведения музыки.
- Готовая ссылка для OBS с сохранёнными настройками каждого виджета.
- Работа в трее: скрытое окно не мешает трансляции.
- Автоматическое скрытие виджета при отсутствии трека или потере связи.

| Тема | Настроение |
| --- | --- |
| **Луна** | Лавандовый акцент и чистая типографика |
| **Мята** | Мятные оттенки и круглая обложка |
| **Закат** | Тёплые персиковые цвета |
| **Neko** | Розовый пиксельный шрифт и кошачьи ушки |

## Быстрый старт

1. Скачай архив **Velune-windows-x64.zip** из раздела Releases репозитория и распакуй его.
2. Запусти **Velune.exe**. Python и отдельный браузер для настройки не нужны.
3. Включи музыку, выбери источник, тему и эффекты в окне программы.
4. Нажми **Копировать ссылку**.
5. В OBS добавь **Источники → Браузер**, вставь ссылку в поле URL и задай размер **700 × 200 px**.

Нужны Windows 10/11 x64 и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Если WebView2 отсутствует, программа сообщит об этом.

### Безопасность загрузки

Сверяй SHA-256 скачанного файла с `SHA256SUMS.txt` из того же Release. Текущая сборка 1.0.3 не подписана, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе, а некоторые эвристические антивирусы — общий ML-детект. Подробный разбор, план подписи и порядок отправки ложных срабатываний: [docs/SIGNING-AND-ANTIVIRUS.md](docs/SIGNING-AND-ANTIVIRUS.md). Модель угроз и сообщение об уязвимости: [SECURITY.md](SECURITY.md).

Клетчатый фон в предпросмотре показывает прозрачность и не попадает в OBS. При выключенных подложке и свечении за треком нет карточки или размытого фона. Режим «Пример» не включается в копируемую ссылку.

### Работа в фоне

Кнопка **Свернуть в фон**, крестик и обычное сворачивание скрывают окно в системный трей. Чтобы вернуть настройки, нажми значок Velune возле часов или выбери **Открыть Velune** в его меню. Полностью завершить программу можно через **Выход** в меню значка. Если значок не виден, проверь скрытые значки Windows.

Во время стрима Velune должна оставаться запущенной. Одновременно запускай один экземпляр: локальный сервер использует порт `8765`.

### Источники и ссылки

Приложение должно публиковать Windows Media Session. Если источник не появился, включи воспроизведение и нажми ↻. Сначала Velune ищет активную сессию Яндекс Музыки, затем любой воспроизводящийся источник. Яндекс Браузер часто отображается в списке как `browser.exe` — его можно выбрать вручную и заново скопировать ссылку для OBS.

### VK или Яндекс Браузер не появляется

Некоторые версии Яндекс Браузера не передают медиасессию сайта в Windows даже при включённом `Hardware Media Key Handling`. В этом случае установи локальное расширение из папки `browser-extension`:

1. Открой `browser://extensions`.
2. Включи **Режим разработчика**.
3. Нажми **Загрузить распакованное расширение** и выбери папку `browser-extension` рядом с `Velune.exe`.
4. Обнови вкладку VK или Яндекс Музыки и включи трек.
5. В Velune нажми ↻: появится `browser:vk.com` или `browser:music.yandex.ru`.

Расширение работает только на страницах VK и Яндекс Музыки и отправляет название, исполнителя, обложку и позицию на локальный адрес `127.0.0.1:8765`. В интернет данные не отправляются.

Браузер может объединять несколько сайтов под одним идентификатором. Выбор браузера не гарантирует, что трек относится именно к Яндекс Музыке: останови остальные медиа или используй отдельное приложение.

Пример ссылки для источника OBS:

```text
http://127.0.0.1:8765/overlay?theme=neko&source=ru.yandex.desktop.music&backdrop=1&glow=1
```

Тема, источник и эффекты закрепляются в ссылке. Можно создать несколько виджетов с разными настройками. После изменения оформления уже добавленного виджета скопируй новую ссылку в OBS.

Настройки программы сохраняются в `%LOCALAPPDATA%/MusicStudio/WebView`; прежнее имя папки оставлено для совместимости. Адрес `/` открывает локальную страницу настроек, `/overlay` — сам виджет.

## Запуск из исходников

Рекомендуется **Python 3.14 x64** — на нём проверена текущая сборка.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Активация окружения не требуется. Дополнительные режимы:

```powershell
.\.venv\Scripts\python.exe app.py --headless
.\.venv\Scripts\python.exe app.py --list-sources
.\.venv\Scripts\python.exe app.py --source "Brave"
```

`--headless` запускает только сервер. `--source` задаёт источник по умолчанию; поиск CLI допускает часть идентификатора и не учитывает регистр. Источник в ссылке из интерфейса выбирается по точному идентификатору.

## Сборка и проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `dist/Velune.exe` и **`dist/Velune-windows-x64.zip`**. Архив включает лицензию Velune, уведомления, лицензии зависимостей и исходники pystray. Публикуй архив целиком в GitHub Releases. Перед повторной сборкой закрой предыдущий exe через меню трея.

`requirements-lock.txt` фиксирует версии зависимостей текущей сборки. Сборка Windows и проверки также доступны в GitHub Actions; workflow сохраняет архив как артефакт, без автоматической публикации релиза.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node tests/test_frontend.cjs
node tests/test_panel.cjs
node tests/test_extension.cjs
```

Проверки JavaScript требуют Node.js. Тесты проверяют выбор источника, обложки, устаревшие данные, настройки ссылки и жизненный цикл трея.
