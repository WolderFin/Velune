# Пользовательский CSS в Velune

Velune 1.2.0 позволяет хранить собственные стили отдельно от EXE и применять их поверх выбранной темы.

## Как включить

1. Открой настройки Velune.
2. Найди блок **Свой CSS**.
3. Измени шаблон и нажми **Сохранить CSS**.
4. Velune автоматически включит переключатель **Применять** и добавит `custom=1` в ссылку OBS.
5. Скопируй обновлённую ссылку в источник «Браузер» или обнови существующий источник.

CSS хранится локально в `%LOCALAPPDATA%\Velune\custom.css`. Кнопка **Сбросить** очищает файл и выключает пользовательские стили в ссылке.

## Переменные

```css
:root {
  --accent: #b7a3ff;
  --text: #ffffff;
  --secondary: #d8d5e4;
  --cover-radius: 16px;
  --title-size: 27px;
}
```

## Основные селекторы

| Селектор | Элемент |
| --- | --- |
| `.stage` | Область размером с источник OBS |
| `.card` | Весь музыкальный виджет |
| `.cover-wrap` | Контейнер обложки |
| `.cover` | Изображение обложки |
| `.label` | Строка «Сейчас играет» |
| `.title` | Название трека |
| `.artist` | Исполнитель |
| `.trackbar` | Фон шкалы прогресса |
| `.progress` | Заполненная часть прогресса |
| `.times` | Текущее время и длительность |
| `.wave` | Анимированный индикатор звука |

## Примеры

Карточка с синим акцентом:

```css
:root {
  --accent: #59b8ff;
  --title-size: 30px;
}

.card {
  background: rgba(8, 16, 28, 0.88);
  border: 1px solid rgba(89, 184, 255, 0.4);
  border-radius: 18px;
  padding: 18px;
}
```

Компактный виджет без обложки:

```css
.cover-wrap,
.wave {
  display: none;
}

.card {
  max-width: 520px;
}
```

CSS загружается только с локального адреса Velune. Приложение должно оставаться запущенным или свёрнутым в трей, как и для обычного OBS-оверлея.
